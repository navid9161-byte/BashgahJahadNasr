# ریلز متحرک پوستر «هجدهمین جشنوارهٔ موسیقی نواحی ایران»

- `src/poster.jpg` — پوستر اصلی (۷۲۰×۱۲۸۰)
- `work/` — نوازنده‌های جداشده (کمانچه، نی)، پس‌زمینهٔ تمیز بدون نوازنده و باکس لوگو، موسیقی
- `render.py` — ساخت ویدیو: `python3 render.py` (پیش‌نمایش: `python3 render.py 2 6`)
- `out/navahi-reel.mp4` — خروجی نهایی: ریلز ۱۰۸۰×۱۹۲۰، ۳۰fps، ۱۵ ثانیه، با موسیقی

موسیقی: قطعهٔ بی‌کلام ساخته‌شده با هوش مصنوعی (ElevenLabs Music در Higgsfield)، کمانچه و نی با ضرب، حدود ۹۹ BPM.

## روش ب — حرکت واقعی با هوش مصنوعی
- `work/b/*-start.png` — هر نوازنده جدا روی رنگ زمینهٔ پوستر (تصویر شروع و پایان کلیپ)
- `work/b/kamancheh.mp4`, `work/b/ney.mp4` — کلیپ‌های ۵ ثانیه‌ای Kling 3.0 (رقص و ساز زدن، فریم اول = آخر برای لوپ بی‌درز)
- `render_b.py` — حذف رنگ زمینه، کوچک‌کردن به اندازهٔ پوستر، ورود از دو طرف و لوپ: `python3 render_b.py`
- `out/navahi-reel-b.mp4` — خروجی روش ب (۱۰۸۰×۱۹۲۰، ۱۵ ثانیه، با همان موسیقی و افکت‌ها)

## نسخهٔ ۲۰ ثانیه‌ای (موسیقی شادتر، نی جلوتر)
- `work/music2.mp3` — آهنگ جدید (نی ساز اصلی، کمانچه، ضرب سبک، ۱۱۵ BPM)
- `work/music2-final.mp3` — همان آهنگ، روی ضرب تا ۲۰ ثانیه کشیده شده + EQ برای جلوتر بودن نی و کمانچه
- `work/music2-alt-happier.mp3` — آهنگ جایگزین (شاد، بدون تأکید روی نی)
- `out/navahi-reel-b-20s.mp4` — خروجی نهایی روش ب، ۲۰ ثانیه

# ریلز متحرک پوستر «هجدهمین جشنوارهٔ موسیقی نواحی ایران»

- `src/poster.jpg` — پوستر اصلی (۷۲۰×۱۲۸۰)
- `work/` — نوازنده‌های جداشده (کمانچه، نی)، پس‌زمینهٔ تمیز بدون نوازنده و باکس لوگو، موسیقی
- `render.py` — ساخت ویدیو: `python3 render.py` (پیش‌نمایش: `python3 render.py 2 6`)
- `out/navahi-reel.mp4` — خروجی نهایی: ریلز ۱۰۸۰×۱۹۲۰، ۳۰fps، ۱۵ ثانیه، با موسیقی

موسیقی: قطعهٔ بی‌کلام ساخته‌شده با هوش مصنوعی (ElevenLabs Music در Higgsfield)، کمانچه و نی با ضرب، حدود ۹۹ BPM.

# سامانه باشگاه فرهنگی ورزشی جهاد نصر کرمان

وب‌سایت و سامانه جامع باشگاه: سایت عمومی، پنل پرسنل (ثبت‌نام، ثبت‌نام آنلاین کلاس‌ها، نظرسنجی و نیازسنجی) و پنل مدیریت.

## امکانات

**سایت عمومی (فارسی، راست‌چین، واکنش‌گرا)**
- صفحه اصلی مطابق طرح (`docs/homepage-mockup.png`) با فرم ورود
- معرفی باشگاه، محورهای فعالیت، اماکن و چشم‌انداز
- رشته‌های ورزشی و صفحه هر رشته
- جدول برنامه کلاس‌ها (با فیلتر شهر)
- اخبار و اطلاعیه‌ها، گالری تصاویر (آلبوم‌بندی)
- تماس با ما (فرم پیام)

**پنل پرسنل**
- ثبت‌نام با اطلاعات کامل پرسنلی (کد ملی با اعتبارسنجی، کد پرسنلی، اطلاعات سازمانی، سلامت، تماس اضطراری، رشته‌های مورد علاقه، عکس)
- ورود با کد ملی یا کد پرسنلی و رمز عبور
- عضویت پس از تأیید مدیر فعال می‌شود
- درخواست ثبت‌نام در کلاس‌ها (کنترل ظرفیت و جنسیت) و پیگیری وضعیت
- شرکت در نظرسنجی‌ها و نیازسنجی ورزشی
- ویرایش اطلاعات و تغییر رمز

**پنل مدیریت**
- پیشخوان آماری
- مدیریت پرسنل: جستجو و فیلتر، تأیید/رد/تعلیق، ویرایش اطلاعات، بازنشانی رمز
- تأیید یا رد درخواست‌های ثبت‌نام کلاس
- تعریف کلاس‌ها، رشته‌ها، اخبار و گالری
- ساخت نظرسنجی و نیازسنجی دلخواه (تک‌گزینه‌ای، چندگزینه‌ای، امتیازدهی، تشریحی) و مشاهده نتایج به صورت نمودار
- خروجی اکسل (CSV) از پرسنل، ثبت‌نام‌ها و پاسخ‌های نظرسنجی
- صندوق پیام‌های تماس با ما

## فناوری

Next.js 15 · React 19 · TypeScript · Tailwind CSS 4 · Prisma · SQLite · فونت وزیرمتن (بدون وابستگی به سرویس خارجی)

## اجرای محلی

```bash
npm install
cp .env.example .env        # سپس AUTH_SECRET و رمز مدیر را تغییر دهید
npm run setup               # ساخت پایگاه داده و داده‌های اولیه
npm run dev                 # http://localhost:3000
```

ورود مدیر با `ADMIN_USERNAME` و `ADMIN_PASSWORD` تعریف‌شده در `.env` انجام می‌شود (پیش‌فرض: `admin` / `Admin@1234`).
**بلافاصله پس از اولین ورود، از «حساب کاربری من» رمز را تغییر دهید.**

## استقرار روی لیارا (Docker)

ساخت برنامه روی لیارا (داخل ایران) به دلیل دانلود پکیج‌ها از محدودیت زمانی ۵ دقیقه بیشتر می‌شد. به همین دلیل:

1. با هر push، **GitHub Actions** (`.github/workflows/build-liara.yml`) برنامه را می‌سازد، روی `node:22-alpine` تست می‌کند و بسته آماده را در شاخه **`liara-deploy`** منتشر می‌کند.
2. برنامه Docker لیارا (`bashgahjn`) از طریق «اتصال GitHub» به شاخه `liara-deploy` وصل است و فقط بسته آماده را کپی و اجرا می‌کند (چند ثانیه).

- دیسک ماندگار `data` در مسیر `/app/data` (پایگاه داده و تصاویر) با هر استقرار حفظ می‌شود.
- تغییرات پایگاه داده به صورت فایل SQL در `prisma/migrations` نگهداری و هنگام شروع با `prisma/migrate.mjs` اعمال می‌شود.
  برای تغییر مدل داده: پس از ویرایش `schema.prisma`، فایل مهاجرت جدید را با
  `npx prisma migrate diff --from-schema-datamodel <نسخه قبلی> --to-schema-datamodel prisma/schema.prisma --script` بسازید.
- متغیرهای محیطی اختیاری: `ADMIN_USERNAME`، `ADMIN_PASSWORD`، `AUTH_SECRET` (در صورت تعریف نشدن خودکار ساخته می‌شود).

## استقرار روی سرور (لینوکس)

```bash
npm ci
npm run setup               # فقط بار اول
npm run build
PORT=3000 npm start         # پیشنهاد: اجرا با pm2 یا systemd و nginx به عنوان reverse proxy
```

- سایت باید با **HTTPS** سرویس شود (کوکی ورود فقط روی HTTPS ارسال می‌شود). برای تست موقت روی HTTP مقدار `INSECURE_COOKIES=1` را تنظیم کنید.
- **پشتیبان‌گیری:** فایل پایگاه داده `prisma/club.db` و پوشه تصاویر `storage/uploads` را به صورت منظم پشتیبان بگیرید.
- برای سوئیچ به PostgreSQL کافی است `provider` در `prisma/schema.prisma` و `DATABASE_URL` تغییر کند.

## ساختار پروژه

```
app/(site)/     صفحات سایت عمومی
app/panel/      پنل پرسنل
app/admin/      پنل مدیریت
app/actions/    منطق سمت سرور (Server Actions)
app/api/        سرو فایل‌ها و خروجی اکسل
components/     اجزای رابط کاربری
lib/            احراز هویت، پایگاه داده، اطلاعات باشگاه (lib/site.ts)
prisma/         مدل داده و داده‌های اولیه
```

اطلاعات ثابت باشگاه (آدرس، تلفن، معرفی، محورهای فعالیت و …) در `lib/site.ts` قرار دارد.
